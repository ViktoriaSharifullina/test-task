# Обработка заказов

CLI-скрипт на PHP для обработки списка заказов в формате JSON.

## Требования

- PHP 8.1 или выше.
- Расширение JSON, входящее в стандартную поставку PHP.

## Инструкция по запуску

Запустите скрипт со встроенными тестовыми данными:

```bash
php orders.php
```

Для обработки JSON-файла передайте его путь первым аргументом:

```bash
php orders.php orders.json
```

Также JSON можно передать через стандартный ввод:

```bash
cat orders.json | php orders.php -
```

При успешной обработке результат выводится в stdout в формате JSON. При ошибке сообщение выводится в stderr, а скрипт завершается с кодом `1`.

## Пример результата

Для встроенных данных программа выводит:

```json
{
    "paid_count": 3,
    "paid_total_amount": 4500,
    "most_expensive_paid_order": {
        "id": 103,
        "amount": 3000
    },
    "orders_by_status": {
        "paid": 3,
        "pending": 1
    }
}
```

Основные результаты:

- оплаченных заказов: `3`;
- общая сумма оплаченных заказов: `4500`;
- самый дорогой оплаченный заказ: № `103`, сумма `3000`.

Дополнительно реализована группировка всех заказов по статусам с подсчётом количества заказов в каждой группе.

## Обработка ошибок

- Если JSON не удалось декодировать, программа выводит сообщение об ошибке и завершает работу с кодом `1`.
- Если корневое значение не является непустым массивом заказов, программа отклоняет входные данные.
- Если у заказа отсутствует обязательное поле `id`, `customer`, `amount` или `status`, программа сообщает об ошибке и не обрабатывает список частично.
- `id` должен быть положительным целым числом, а `customer` — непустой строкой.
- `amount` должен быть целым или дробным числом, неотрицательным и конечным. Строковые значения сумм не принимаются.
- Разрешены статусы `paid` и `pending`. Неизвестный статус считается ошибкой.
- При любой ошибке результаты не выводятся, чтобы не создать частично достоверный отчёт.
