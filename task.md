Тестовое задание: обработка заказов

Цель: проверить навыки программирования на PHP, умение работать с массивами и JSON, обрабатывать ошибки и писать понятный код.

Ориентировочное время выполнения: 60–90 минут.

Задача

Есть список заказов в формате JSON:

[
{
"id": 101,
"customer": "Иван",
"amount": 1500,
"status": "paid"
},
{
"id": 102,
"customer": "Мария",
"amount": 2500,
"status": "pending"
},
{
"id": 103,
"customer": "Пётр",
"amount": 3000,
"status": "paid"
},
{
"id": 104,
"customer": "Анна",
"amount": 0,
"status": "paid"
}
]
Необходимо написать PHP-скрипт, который обрабатывает этот список.

Часть 1. Основная логика

Реализуйте следующие функции:

1. Получение списка заказов из JSON.
2. Выбор заказов со статусом paid.
3. Подсчёт общей суммы оплаченных заказов.
4. Подсчёт количества оплаченных заказов.
5. Определение самого дорогого оплаченного заказа.

Ожидаемый результат для исходных данных:

* Количество оплаченных заказов: 3.
* Общая сумма оплаченных заказов: 4500.
* Самый дорогой оплаченный заказ: № 103 на сумму 3000.

Часть 2. Проверка данных

Добавьте обработку некорректных данных:

* JSON не удалось декодировать.
* У заказа отсутствует обязательное поле.
* Сумма заказа отрицательная или имеет некорректный тип.
* Статус заказа неизвестен.

Опишите, как программа должна вести себя в каждом из этих случаев.

Часть 3. Дополнительное задание

Реализуйте одну дополнительную возможность на выбор:

Вариант А. Добавьте фильтрацию заказов по минимальной сумме.

Вариант Б. Добавьте группировку заказов по статусам с подсчётом количества заказов в каждой группе.

Вариант В. Сохраните результаты обработки в отдельный JSON-файл.

Требования

* PHP 8.1 или выше.
* Не требуется создавать сайт, HTML-страницы или пользовательский интерфейс.
* Код должен запускаться из командной строки.
* Разрешено использовать стандартные возможности PHP.
* Можно пользоваться документацией и ИИ-инструментами
